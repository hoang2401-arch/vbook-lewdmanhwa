# Cập nhật Góc Truyện Tranh v2

**Repository:** hoang2401-arch/vbook-lewdmanhwa

1. Thay file `plugin.json` ở thư mục gốc.
2. Thay file `goctruyentranhvui30/plugin.zip` trong thư mục nguồn.
3. `icon.png` không thay đổi và không bắt buộc upload lại.
4. Commit, làm mới kho rồi cập nhật extension trong vBook lên version 2.
5. Test tab `Mới cập nhật`; sau đó mở `Ta Là Gia Sư Của Ma Vương Yếu Ớt`, `Chương 1`.
6. Nếu chưa được, lấy log bắt đầu `GocTruyen v2:` bằng VBook Rule Tester.

**Giới hạn:** Chưa kiểm thử được ảnh chương thực tế (trang có bước kiểm tra trạng thái tài khoản). Bản v2 cải thiện cách tìm ảnh và báo lỗi chứ chưa xác nhận fix đọc chương.
